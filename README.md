# Idle Kingdoms (Single-Player Demo)

Offline-capable, mobile-first web demo built from the Game Bible and compact JSON database.

## Commands

```bash
npm install
npm run dev
npm test
npm run build
```

## Notes

- Launches directly into the single-player experience (no login).
- Loads `content/data/game-database.json`.
- Creates and reloads one local save automatically.
